# Frequency Generator — мобильное приложение для визуализации фигур Лиссажу

![Android](https://img.shields.io/badge/Android-8.0%2B-green)
![Java](https://img.shields.io/badge/Java-11-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

Мобильное приложение для платформы Android, предназначенное для генерации звуковых сигналов и визуализации фигур Лиссажу. Разработано в рамках курсовой работы по теме «Разработка мобильного приложения для оборудования технопарка на примере эксперимента с фигурами Лиссажу».

## Описание

Приложение позволяет:
- Генерировать звуковые сигналы трёх форм: **синусоидальной**, **прямоугольной**, **треугольной**;
- Настраивать частоту в диапазоне от **20 до 20 000 Гц** (индивидуально для каждой из трёх частот);
- Визуализировать **фигуры Лиссажу** в реальном времени;
- Отображать форму звуковой волны (осциллограмму);
- Передавать звук на внешнее устройство (лазерный проектор) через **Bluetooth**;
- Работать в **портретной и ландшафтной** ориентациях;
- Открывать график в **полноэкранном режиме** с возможностью масштабирования.

## Назначение

Приложение предназначено для использования в технопарке в связке с лазерным проектором, оснащённым мембранной с зеркалом. Под воздействием звуковых колебаний, поступающих с мобильного устройства, зеркало вибрирует, и лазерный луч вычерчивает на стене сложные фигуры Лиссажу.

## Технологии

- **Язык:** Java 11
- **Платформа:** Android (minSdk 24, targetSdk 36)
- **Среда разработки:** Android Studio
- **Генерация звука:** `android.media.AudioTrack`
- **Визуализация:** `android.graphics.Canvas`, кастомные View
- **Bluetooth:** `BluetoothAdapter`, `BluetoothSocket` (SPP)
- **Система контроля версий:** Git
